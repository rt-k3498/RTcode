## Find your bearings

The top strip identifies your workspace and places terminal layout, commands, and Settings within reach. Files, Search, and Git live on the left. Your code stays in one central editor group. The status strip shows document position, language, save state, and trust.

## Start a session

Choose the workspace name or Open a workspace to select a local folder. Browse files immediately in Restricted Mode. Trust only folders whose contents you understand before starting a terminal or formatter.

## Help stays close

The R_> logo always returns here. F1 does the same. Settings opens over your workbench: editor models and terminals remain alive. Escape or Back to editor restores your context.

## An honest early build

This version implements a local editing workbench. The browser preview uses sample files in memory. It cannot launch shells or read your computer. Read Updates and limitations for the implementation boundary.
