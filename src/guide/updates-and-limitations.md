## Available in this build

Tauri/Solid workbench; Monaco tabs, editing, built-in TS/JS intelligence, JSON/CSS validation, HTML completion, and a Problems panel; native scoped tree and create; revision-checked UTF-8 save; native search; Git status, refs, history, staging, local switch and patch view; xterm PTY sessions and SSH launch; external formatter; SQLite preferences and trust; bundled searchable Guide.

## Still to implement

External LSP brokerage, framework language plugins, continuous project file watching, VSIX inspection/install, file watcher and external-change comparison, Save As, explorer rename/trash UI, recovery buffers, recent-session restoration, SSH favorites/config handles, virtualized large lists, rich diff models, complete setting/action/error coverage, signed updater, release packaging, and performance gates.

## Validation scope

Browser interaction and native checks on the development machine do not establish Windows or Linux support. IME, ConPTY, host-key prompts, signing, upgrades, process descendants, and all support-matrix requirements need packaged tests on real target systems.

## Roadmap honesty

Web extensions and remote workspaces remain conditional. No Marketplace access, Node extension host, AI chat, debugger, or Git network controls are included.
