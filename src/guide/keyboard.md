## Workbench

F1: open Settings → Guide. Cmd/Ctrl+Shift+P: command palette. Cmd/Ctrl+O: open folder. Cmd/Ctrl+S: save. Cmd/Ctrl+W: close active tab. Cmd/Ctrl+B: toggle sidebar.

## Tools

Cmd/Ctrl+Shift+E: Files. Cmd/Ctrl+Shift+F: Search. Cmd/Ctrl+Shift+G: Git. Cmd/Ctrl+J: hide/show terminal. Cmd/Ctrl+backtick: focus terminal. Cmd/Ctrl+Shift+backtick: new terminal. Shift+Alt+F: format. Cmd/Ctrl+Shift+M: Problems. Ctrl+Space: completion. F12: definition. F2: rename. F8/Shift+F8: next/previous diagnostic. Language-specific actions require a supported language service.

## Navigation

Tab moves between controls. Enter and Space activate buttons, including RTcode. Escape closes Settings or a dialog. Arrow keys on splitters resize panes. Cmd/Ctrl+F in Guide focuses its search field. Editable bindings and several planned advanced shortcuts remain pending.
