## The console system

Retro 82 uses dark engineered layers, warm amber command signals, cool teal live signals, hairlines, square geometry, and monospace typography. No scanlines, animated backgrounds, or glowing code text obscure work.

## Personalization

Settings → Editor controls font size, word wrap, and minimap. Appearance offers high contrast, restrained motion, and editable base colors for the primary accent, secondary accent, background, surface, and text. Defaults use orange and teal. Color changes apply immediately to the workbench, R_> logo, editor, and live terminals. Reset colors restores the default palette. System reduced-motion preference is respected. Terminal placement is controlled in the top toolbar.

## Responsive layout

The minimum desktop window is 820 × 560. Below 1000 px terminals move below the editor; when both panes are enabled they share that bottom row and the sidebar becomes a rail with a focus-open overlay. Resize separators support arrow keys.
