## Workspace

A local folder and the scoped authority to operate on its files. Restricted Mode allows editing while blocking code execution.

## PTY

A pseudoterminal: the native terminal interface that connects an interactive shell to xterm.js. xterm.js is the renderer, not a shell.

## LSP

Language Server Protocol: a structured conversation between an editor and a language tool. Monaco alone does not supply a server.

## Git and extensions

Staged changes are in Git’s index. A remote-tracking branch is a local record of a remote ref, not a live network connection. VSIX is an archive format, not proof of API compatibility. A capability limits what a webview can ask the native host to do.
