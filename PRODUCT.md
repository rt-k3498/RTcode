# RTcode

## Register
product

## Platform
web

The interface runs inside a native Tauri v2 desktop window on macOS, Windows, and Linux.

## Users
A single developer editing local projects, operating shells, inspecting Git, and connecting to SSH hosts.

## Product Purpose
A narrow, dependable local IDE: one editor group, three workbench tabs, a movable terminal, and an offline Guide.

## Positioning
A personal operator console with Rust-owned system authority and an honest language-tooling and extension compatibility model.

## Brand Personality
Precise, technical, calm. Original Omarchy-influenced retro-futurism.

## Anti-references
Generic VS Code clones, rounded SaaS cards, neon gamer interfaces, fake CRT distortion, and decorative instrumentation.

## Design Principles
Preserve user data. Explain every unavailable feature. Keep execution explicit and trust-gated. Maintain one coherent surface. Ship documentation with behavior.

## Accessibility & Inclusion
WCAG AA text, keyboard operation, visible focus, reduced motion, non-color status, and a desktop minimum of 820 × 560.
